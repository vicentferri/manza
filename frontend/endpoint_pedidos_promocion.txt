=========================================================
  ENDPOINT: GET /sm/pedidos_promocion
  Pedidos en curso para centros con promoción activa
  Stack: Node.js + Express + SQL Server / MySQL
=========================================================


-- DESCRIPCIÓN --

  Devuelve, para cada pedido en cola (SOL_PEDIDOS_COLA) cuyo
  centro de entrega tenga una promoción activa en la fecha del
  pedido, la referencia de cliente y la cantidad total de
  unidades de artículo tipo enrollable (tipo=1, articulo=1).

  Columnas devueltas:
    cliente_entrega   INT        -- ID del centro de entrega
    refcliente        VARCHAR    -- Referencia del cliente en el pedido
    total             INT        -- Suma de unidades (t1.cantidad)

  No requiere parámetros de entrada.
  No requiere cambios en la BD (usa tablas y vista ya existentes).


-- CÓDIGO DEL ENDPOINT --

  Añadir en el fichero de rutas /sm (donde estén el resto de rutas /sm):

--------------------------------------------------------------

// ─── GET /sm/pedidos_promocion ───────────────────────────────────────────────
// Pedidos en período de promoción activa, agrupados por centro y referencia
router.get('/pedidos_promocion', async (req, res) => {
  try {

    // --- SQL Server ---
    const result = await pool.request().query(`
      SELECT
        head.cliente_entrega,
        head.refcliente,
        SUM(t1.cantidad) AS total
      FROM  SOL_PEDIDOS_COLA              head
      INNER JOIN sol_pedidos_cola_lineas  lin ON lin.idrow = head.idrow
      INNER JOIN sol_pedidos_cola_tipo_1  t1  ON t1.idrow  = lin.id
      INNER JOIN vw_nh_clientes_promociones pro
                                          ON  pro.idrow = head.CLIENTE_ENTREGA
      WHERE CAST(head.fecha AS date) >= pro.desde
        AND CAST(head.fecha AS date) <= pro.hasta
        AND t1.tipo    = 1
        AND lin.articulo = 1
      GROUP BY head.cliente_entrega, head.refcliente
      ORDER BY head.cliente_entrega, head.refcliente
    `);
    return res.json({ Table: result.recordset });

    // --- MySQL ---

-- NOTA: VISTA REQUERIDA --

  El endpoint depende de la vista vw_nh_clientes_promociones,
  que debe existir en la BD. Esta vista es la misma que usa
  el endpoint GET /sm/promociones_activas.
